# Beobachtungsbogen – Auswertung

Kleines Web-Werkzeug für Lehrkräfte: Pro Kind wird ein Beobachtungsbogen ausgefüllt. Daraus entsteht eine zweiseitige, druckfertige A4-Auswertung.

- **Seite 1:** Ergebnisse aller Aussagen mit Bereichsdurchschnitten
- **Seite 2:** Netzdiagramm, Werte pro Bereich, Noten, gymnasiale Empfehlung (Ja/Nein), Bemerkung, Unterschriften

## Datenschutz

Die Seite ist eine einzelne statische HTML-Datei. Alle Eingaben werden **nur im Browser der Nutzerin bzw. des Nutzers** gespeichert (localStorage). Es werden keine Daten an einen Server übertragen, auch nicht an GitHub. In diesem Repository liegen keine Schülerdaten.

Zum Übertragen auf ein anderes Gerät: „Daten sichern“ → Datei → auf dem anderen Gerät „Daten laden“.

## Fragebogen anpassen

Oben rechts auf „Schule & Fragebogen“ klicken. Zeilen, die mit `#` beginnen, sind Bereiche, alle anderen Zeilen sind Aussagen.
